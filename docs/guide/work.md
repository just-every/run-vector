# Plan and track the work

## Issues

**Issues** is a paged list of all the work. Filter by status, priority, assignee, team, project, cycle, label, due date, blocked state or parent; sort and group it the way you need. Completed issues stay out of the list until you choose Completed. Select several rows to change their status, assignee, priority, project, cycle or labels together; if one of them cannot change, none of them do, and Vector names the ones that need attention.

Each issue keeps its description, comments, links, files, dependencies, parent and children, and a history of every change.

## The Board

The **Board** shows one team's workflow at a time, a column per status. Change a card's status from the selector on the card. On a phone, choose which column to see from the column selector.

## Saved views

Save any set of filters, sort and grouping, as a list or a board, as a view just for you or shared with the team. Shared views appear under **Saved views** in the sidebar. Anyone can open or copy a shared view; only the person who saved it can change or delete it.

## Projects and cycles

**Projects** group work toward a goal, with a lead, an optional target date and a status you set: Planned, Active, Completed or Canceled. Archiving a project hides it but keeps its issues.

**Cycles** are stretches of time for one team, with an optional capacity. When a cycle ends, unstarted and started work rolls into the next cycle; if there is no next cycle, it is uncommitted and the closed cycle says so. A closed cycle keeps its numbers as they were.

## Search and shortcuts

Search finds issue identifiers and text, projects, labels and saved views. Press Command-K or Ctrl-K to open search anywhere. Press C for a new issue, and G then M, G then C or G then P for My work, Current or Projects.
