The selected family supports only actual additions of a stable label identity, a stable priority value and an existing Slack destination explicitly subscribed to automation-rule notifications and bound by a current Owner or Admin. It does not call arbitrary URLs, create channels or issue authority. Monthly budgets use UTC evaluation months, count attempted admitted runs and do not reset on a save. Budget-stopped receipts never replay. A rule's own priority act is not a producer. Other rule families remain unimplemented.

Restored rules are held individually even after global effect review. An explicit versioned save may enable future additions, but terminalizes historical pending receipts. Delivery uncertainty is a visible failed state and is never automatically replayed. A repair save clears that version's failure; owner notices are once per failing rule version, through the owner's private native Inbox using the existing reminder category.
