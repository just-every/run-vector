# Vector product target

Vector is a self-hosted internal issue tracker for one business. One workspace has equal operators: teams organize work, not access. Evidence-led intake feeds an explainable Current stream; My work is personal execution; projects expose the facts behind risk. CONTRACT.md and BASELINE.md define the requirements; HANDOVER.md records implemented scope and limitations.

## Request ownership

| Surface | Owner and admission |
| --- | --- |
| `/`, `/signin` | Public TanStack Start documents |
| `/app` and implemented descendants | Start; valid session before private loader work |
| `/_serverFn/*` | Start transport; each private handler validates session |
| `/api` and descendants | Hono; native session, server validation and mutation Origin checks |
| Declared authentication routes | Auth handler; validated confirmation and session policy |
| `/health` | Public health response |

Runtime is one Worker with D1 and R2. The loopback-only local outbox supports development; deployments require configured mail. Private data and authorization must survive requests, concurrent changes and runtime restart. No broader requirement is waived by a partial implementation or local verification result.
